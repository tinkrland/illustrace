# factories (charatrace)

charatrace's own factories, separate from illustrace's `/factories`. same principle, different subject: illustrace's factories generate editable marks, type, and surface treatments; charatrace's generate the expressive and doodled asset families that sit closer to the character herself, faces, expressions, loose linework, the vocabulary a humanoid doodle character is built out of.

same two rules as illustrace's factories: every output is an editable preset, never a flattened render, and randomize is a browsing affordance only, the saved asset is the deterministic program.

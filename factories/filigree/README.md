# filigree (ornament factory)

the decorative-detail factory: flourishes, swashes, ornamental frames, corner pieces, dividers, the curlicues and vining ornament that turn a mark into a mark *with ceremony*. procedural, growth-based, and fully editable.

## what it makes

- flourishes and swashes: parametric curves with growth, taper, curl, and density parameters
- ornamental frames: corner ornaments, borders, cartouches that resize around whatever they frame
- dividers and sprigs: small standalone ornaments for editorial and packaging use

## the growth model (sketch)

ornament wants to be procedural: a filigree is a growth program (branch, curl, leaf, recurse) with art-direction parameters, not a stamp library. each element remains a vector path with control points exposed, so procedural generation proposes and the user disposes. generated, browsed, then hand-finished and saved as the deterministic program, same intent rule as every factory.
